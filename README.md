# SeoulMate — K-Beauty E-commerce System Analysis

> учебный проект по системному и бизнес-анализу

## About the Project

SeoulMate — концептуальная информационная система
интернет-магазина корейской косметики.

Цель проекта — спроектировать систему,
которая автоматизирует каталог товаров,
подбор косметики, оформление заказов,
оплату, управление остатками и доставку.
